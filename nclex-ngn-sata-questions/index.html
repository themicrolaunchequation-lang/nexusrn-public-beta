NCLEX NGN SATA Questions Explained

SATA questions are not a guessing game. Each option must be judged as its own true-or-false decision based on the client data.

Back to NGN Study Hub Review NGN Practice Questions

Select-all-that-apply questions test whether you can evaluate several choices independently. The safest method is to prove each option, not count how many answers feel right.

The learner trap: Students hunt for a magic number of correct answers. There is no safe magic number. The only safe rule is evidence.

What is this question type?

A SATA or multiple-response question asks you to select every option that correctly answers the task. Some choices may be true in general but wrong for the specific client scenario.

The SATA method

  1. Turn each option into true or false. Judge one option at a time.
  2. Use the stem as the rule. The option must answer this question, not a different one.
  3. Demand evidence. If the scenario does not support the option, do not select it.
  4. Watch for qualifiers. Words like first, priority, immediate, expected, and contraindicated change the answer.
  5. Stop counting. There is no reliable number of correct options.

Original sample SATA question

This original public sample is simplified for learning. It is not copied from NCLEX, NCSBN, or any protected NexusRN question bank.

Client scenario

A client with pneumonia has oxygen saturation of 88% on room air, respiratory rate of 30/min, new confusion, productive cough, and decreased oral intake.

Task

Which findings require follow-up? Select all that apply.

  • Oxygen saturation of 88% on room air
  • Respiratory rate of 30/min
  • New confusion

Why these answers make sense

Low oxygen saturation, tachypnea, and new confusion suggest impaired oxygenation or deterioration. Productive cough may be expected with pneumonia, and decreased oral intake needs assessment, but oxygenation-related changes are more urgent.

How this connects to clinical judgment

Recognize cues

Identify which options are supported by abnormal or changing client data.

Analyze cues

Separate expected findings from concerning findings.

Prioritize hypotheses

Select options that match the most important client risk.

Take action

Avoid selecting actions or findings that are not supported by the scenario.

Common mistakes

  • Over-selecting: choosing everything that sounds medically related.
  • Under-selecting: stopping after one good answer even when others are supported.
  • Counting answers: trying to guess whether there should be two, three, or four choices.
  • Ignoring the task: selecting symptoms when the question asks for actions.
  • Choosing true-but-irrelevant options: selecting a statement that is generally true but not supported here.

Practice drill

Before you answer, ask:

  1. What is the question asking me to select?
  2. Is this option supported by the client data?
  3. Is the option true for this client or only true in general?
  4. Does the option match the priority or timing in the stem?
  5. Would I defend this option out loud?
